Decision path Define, solve, prove, review How this workspace works

The engineering question: does this defined towing-axis mechanism steer every mapped wheel correctly and remain physically feasible across the selected articulation range?

  1. Define: bodies, axles, pivots, links, and wheel mappings.
  2. Solve: compute the common maneuver geometry and mechanism pose.
  3. Prove: check closure, steering, collision, and clearance at every pose.
  4. Review: save the evidence, compare the proposal, then submit it for independent approval.
What the result contains

Actual versus ideal wheel angles, mechanism residuals, collision and clearance findings, full-range evidence, and a traceable project revision.

PASS means the configured hard checks pass. FAIL means diagnostic evidence only, never a manufacturing release.
